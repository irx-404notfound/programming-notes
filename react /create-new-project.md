# CREAT NEW PROJECT FOR REACT

```bash
npm create vite@latest
```

```bash
Project name:
ActStudio

Package name:
actstudio

Select a framework:
React

Select a variant:
JavaScript

Install with npm and start now?
Yes
```

> [!NOTE]
> This opens your project in the browser.
```bash
cd name_of_the_project

npm install

npm run dev
```

After running these comands, that appears in your bash:

```bash
VITE v8.0.7 ready in 928 ms

  Local: http://localhost:5173/
  Network: use --host to expose
  press h + enter to show help
```
Next, you can copy the local link and paste it into your favorite browser. 

What gets installed automatically?

- React.
- React DOM (for the browser).
- Vite (development server).
- All configurated.

> [!TIP]
> This step is optional, but recommended.

Install [Visual Studio Code](https://code.visualstudio.com/download) and, within it, install these extensions:

- ES7 + React Snippets
- Prettier (for automatically reset)
- Auto Rename Tag

You can also install the [React Developer Tools](https://chromewebstore.google.com/detail/react-developer-tools/fmkadmapgofadopljbjfkapdkoienihi) extension in your browser to view your components and debug your app.

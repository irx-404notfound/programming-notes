# 💡 CREATING NEW PROJECT FOR REACT

1. Create new project:

```bash
npm create vite@latest
```

```bash
Project name:
ActStudio

Package name:
actstudio

Select a framework:
React

Select a variant:
JavaScript

Install with npm and start now?
Yes
```

> [!NOTE]
> This opens your project in the browser.
```bash
cd name_of_the_project

npm install

npm run dev
```

After use thoose comands, that appears in your bash:

```bash
VITE v8.0.7 ready in 928 ms

  Local: http://localhost:5173/
  Network: use --host to expose
  press h + enter to show help
```
Then you can copy the local link ant paste in your favorite browser.

# REQUIRED APPLICATIONS FOR REACT

> [!IMPORTANT]
> These applications are required for the correct operation of react, so be sure to install them.

## 🟢 NODE.JS - [DOWNLOAD](https://nodejs.org/en/download)
```
Whithout this app, React doesn't work. It's the most important app.
```
What it does?

- Runs JavaScript outside the browser.
- Allows you to use tools like Vite.
- Includes npm (package manager).

## 🔵 NPM (INCLUDED IN NODE.JS)
```
It installs automatically with Node.js
```
What it does?

- Runs libraries (React, Vite, etc.).
- Runs project commands.
